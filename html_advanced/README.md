# HTML Advanced

This project is part of the Holberton School front-end curriculum. The goal is to build the HTML structure of a website for **Techium**, a fictional digital agency, using only HTML (no CSS yet).

## What this project covers

- Writing a valid HTML5 document (doctype, `lang`, `meta` tags, title, description)
- Using semantic elements: `header`, `nav`, `main`, `section`, `article`, `footer`, `address`
- Headings, paragraphs, lists, links and images (with `alt`, `width` and `height`)
- Inline SVG icons, favicons and quotes (`blockquote`, `cite`)
- Building a styleguide page that shows the website's text, lists, tables and multimedia
- Accessibility basics: image `alt` text and `title` attributes (for example on iframes and SVGs)

## Pages

| File | Description |
|------|-------------|
| `index.html` | Homepage: hero, services, works, about us, latest news, testimonials, contact |
| `about.html` | About page |
| `latest_news.html` | Latest news page |
| `article.html` | Single article page |
| `contact.html` | Contact page |
| `styleguide.html` | Final styleguide page |

## Task files

The numbered files (`0-index.html` to `39-styleguide.html`) are the step-by-step tasks. Each one builds on the previous step until the full homepage and styleguide are done.

## Assets

- `images/`: pictures used in the pages
- `logo-black.png`: Techium logo
- `favicon.ico`, `favicon.png`: site icons

## Requirements

- Files are written in HTML5 and checked with the W3C validator
- All files end with a new line
- No CSS or JavaScript is used in this project
